##2. Difference between the data lake and the data warehouse 


| Feature           | Data Lake                       | Data Warehouse           |
| ----------------- | ------------------------------- | ------------------------ |
| Data Type         | Raw (any format)                | Structured               |
| Schema            | Schema-on-Read                  | Schema-on-Write          |
| Purpose           | Storage + Processing            | Analytics + Reporting    |
| Users             | Data Engineers, Data Scientists | Analysts, Business Users |
| Cost              | Low                             | Higher                   |
| Query Performance | Slower (needs processing)       | Faster for analytics     |
| Example           | Raw logs, JSON, IoT data        | Sales summary table      |

####8.  Is it better to use one Delta table or multiple Delta tables for streaming ingestion? How do you decide?

        If streaming sources share a common schema and are often queried together, 
        I prefer a single Delta table. If schemas differ significantly, data volumes vary greatly, 
        or pipelines need independent scaling, I design multiple Delta tables.
