* Surrogate KEY ::
                  A Surrogate Key is an artificial (system-generated) unique ID given to each row in a dimension table.
                  It has no business meaning.

                  
                  | surrogate_key | customer_id | city      | start_date | end_date   | is_current |
                  | ------------- | ----------- | --------- | ---------- | ---------- | ---------- |
                  | 101           | C1          | Bangalore | 2024-01-01 | 2025-01-01 | N          |
                  | 205           | C1          | Hyderabad | 2025-01-01 | null       | Y          |
